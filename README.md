É preciso ter o [Node.js 22 ou superior](https://nodejs.org/) instalado. Nesta máquina a versão usada foi a 24.

Na pasta do projeto, no terminal:

```bash
npm run install:all
npm run dev
```

O primeiro comando instala as dependências. O segundo sobe a API e o site juntos.

- API: http://localhost:3001
- Site: o endereço que aparecer no terminal, em geral http://localhost:5173
